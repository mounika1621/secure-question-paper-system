# Secure Cloud-Based Question Paper Management System

## 1. Project Title

**Secure Cloud-Based Question Paper Management System**

## 2. Brief Description

This project is a secure web application for managing government/competitive examination question papers. It reduces the risk of unauthorized access, modification and early leakage by using authentication, role-based access control, encryption, hashing, approval workflow, audit logging and time-based controlled release.

## 3. Technologies / Tools Used

- HTML, CSS and JavaScript
- Node.js
- Express.js
- Supabase PostgreSQL database
- Supabase private cloud storage
- AES-256-GCM encryption
- SHA-256 hashing
- JSON Web Token (JWT)
- bcrypt password hashing
- GitHub

## 4. Main Security Features

- Role-Based Access Control (Setter, Reviewer, Administrator, Examination Controller)
- Password hashing using bcrypt
- JWT authentication
- HTTPS/TLS when deployed
- AES-256-GCM encryption before cloud storage
- SHA-256 integrity verification
- Review and approval workflow
- Time-based release
- Audit logs
- Private cloud storage
